Allscott Heath Cricket Club — Linear Scorebook prototype

NETLIFY DEPLOYMENT
1. Go to https://app.netlify.com/drop and sign in.
2. Upload the ZIP if accepted, or unzip it and upload the linear-scorebook-netlify folder.
3. Open the generated https://...netlify.app URL in Safari on your iPad.
4. Test the scoring buttons. In Safari use Share > Add to Home Screen if desired.

IMPORTANT
- This is an early scoring prototype, not verified for official match scoring.
- Saved data uses local browser storage on the device and website origin. Export backups regularly.
- Offline access is NOT guaranteed by this version.
- It does not yet reproduce the exact printable A4 score sheet.
